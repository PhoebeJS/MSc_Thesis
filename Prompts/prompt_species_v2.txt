# date

Only list a date if there is one present within the record and that can be directly tied to the species. If dates are mentioned in the transcribed record but are not related to where the species was found, spotted, captured, etc do NOT include those dates. 

Include the date in a numeric format including only the year (example: if date is given as 'day-month-year', take only 'year'). If the date is in long format, convert it into the numeric and extract the year. Report the year with its century number even if only given the last two digits. If only a year is given, just report the year. If multiple dates are reported, extract the oldest date only if that date is linked to the species being alive.

This value looks like a four-digit number followed by three more values separated by '.' (Example: 1961.8.9.77). The first value is the year the species was recorded in the record and can be listed as the 'date'.
